# Quantifin 中文工作台

2026-09-28，基于 OpenTakeoff d0f552e49b3747126c67a9ee4841831cef8ca591 二次开发。

## 访问

在 web 目录运行 `npm.cmd run dev`，访问终端显示的地址。首页 `/` 为中文工作台，`/takeoff` 为 Quantifin 算量编辑器，直接复用本地画布引擎。原 `?project=` 云项目深链接继续使用原存储入口。

## 功能范围

- 首页从 localStore 读取真实文件数和测量记录；无演示业务统计。
- 导入复用 ingestFiles 与 localStore.addPdf，文件加入同一个本地工作空间。
- 复核汇总分别统计 origin.reviewed 为 false 和 true 的测量；无标记记录不归入已复核。
- 工程量使用 conditionTotals 汇总，将英尺／平方英尺换算为米／平方米，不含损耗加成，CSV 可由 Excel 打开。
- 复核确认在原画布执行；中文页不修改复核状态。
- 算量编辑器主导航、图纸空状态与管理确认、测量工具、比例尺与绘图菜单、饰面属性、复核和报表主要交互已中文化；高级工具的个别提示及原有导出文件的机器可读字段仍沿用英文。组织权限、多人协作、招标语义分析和自动置信度评估尚未接入。
- 图纸属于当前浏览器来源地址，localhost 与 127.0.0.1 的存储互不相通。请保持地址一致并定期导出。

## 自动比例尺与毫米输入（2026-09-29）

- 导入 PDF、扫描件或图片后，打开图纸。印刷比例尺，或至少两条带端点标记且推算一致的毫米尺寸线，可自动填写该页比例尺。扫描图纸在本机运行 OCR；识别不到可靠证据时保持未设置状态。
- 黄色“待核对”表示自动值尚未由人确认。使用比例尺菜单的“K 核对已知尺寸”，在图上点击两个端点，以 mm 输入标注值；确认无误后点“确认自动识别的比例尺”。遇到冲突、局部详图不同比例或无法识别时使用两点校准。
- 扫描件若只有“1:100”文字，没有可交叉核验的尺寸线，不会自动采用，因为图片缩放可能改变像素密度。自动识别给出证据数量，不代表工程量精度或人工审核。
- 当前可直接导入 PDF、图片、ZIP；DWG 需从 CAD 软件导出 PDF 后导入。导出时保留原比例和完整尺寸标注。
- 内部比例尺仍保存为英尺／逻辑像素，以兼容上游算量与既有项目；中文公制输入中的图纸数字按 mm 换算，不改历史记录。OCR 英文数字模型与运行时按需加载，在本地浏览器执行。

## 批量比例尺核对

访问 `/scale-review`，或在工作台、图纸目录和算量工具栏选择“批量比例尺核对”。支持当前已导入的 PDF、图片和 ZIP 中的图纸，多页 PDF 按页列出。

1. 勾选图纸，点击“一键识别选中图纸”。识别只产生建议，支持取消及重新识别；单页失败不阻断后续图纸。
2. 对照右侧原图核对标注。“采用选中建议”可集中采用没有冲突的结果；“确认选中当前比例尺”可集中确认已有值。
3. 矢量 PDF 可输入比例尺分母后“应用到选中图纸”。扫描图请在原图选择两个端点，输入标注毫米值并点击“记录两点校准”。可以依次修正多张图纸后统一保存。
4. 点击“保存 N 张修改”，查看面积和长度变化，再“确认并保存”。预览列出图元几何量合计，含扣减图元，不等同于净工程量报表。保存会重算相关工程量，保留计数、原始几何和其他项目字段；修改前自动建立版本快照。

单个 OCR 比例文字或冲突证据不能批量采用。识别依据不等于人工确认；只有人工点击最终保存才写入确认状态。未保存的建议和修改仅在本页当前会话保留。项目或图纸在其他页面发生变化时，保存会提示重新载入；拼接图的独立比例尺仍在画布核对。
